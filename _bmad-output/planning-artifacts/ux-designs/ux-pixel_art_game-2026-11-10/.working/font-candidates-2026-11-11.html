Pixel font candidates: The Unbroken Chain

2026-11-11. Native 480x270, integer scale x2/x3, HUD on an 8 px grid, text blocks at 12 px line spacing. All samples rendered with Pillow at each font's native pixel size, fontmode 1 (no antialiasing), then nearest-neighbour scaled. Tofu boxes = glyph missing. Red tick in the gutter strip = line wider than the 59 px usable gutter width. Coverage counted from each font's cmap with fontTools.

Gutter strip: label #6e7b8f, amber #ffd27a, HP #a9b4c2 on #07060b, rows every 8 px. Menu panel: #d8c3a0 on Dusk #18100b, rows every 12 px.

None of the four 8 px-class fonts covers Vietnamese stacked diacritics (U+1EA0-1EF9: ầ ồ ở ớ ộ ...); Fusion 8px has the base letters Đ and ư; m5x7 and monogram have Đ but not ư; Pixel Operator 8 has neither. Fusion Pixel 10px/12px (same release, also OFL) do cover VN 90/90 and Cyrillic 89/96, which is relevant if a localised build may use a larger text size. CJK: only Fusion provides it.

Steam Deck physical size: 1280x800 on 7 in, about 215.6 ppi (0.1178 mm per device px). 480x270 fits at x2 (960x540, letterboxed); 1 game px = 2 device px = 0.236 mm. Cap 6 px = 1.41 mm, cap 7 px = 1.65 mm, x-height 4 px = 0.94 mm, x-height 5 px = 1.18 mm. The 'Deck size' images below are sized in CSS mm; browsers assume 96 dpi so they are only approximate unless your display's scaling matches.

Method notes

  • Fonts downloaded to the session scratchpad; nothing executed from them. fontTools 4.68 / Pillow installed into the scratchpad.
  • Native size = unitsPerEm divided by the outline grid unit (GCD of glyph coordinates), i.e. the Godot font size at which one design pixel lands on one screen pixel.
  • In Godot: set that size, antialiasing None, hinting None, subpixel positioning Disabled, and keep the font's line spacing or override to 12.
